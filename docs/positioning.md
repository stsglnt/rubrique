# What rubrique is

The words for the README, `Cargo.toml`, `packaging/linux/rubrique.desktop`
and the GitHub description. Change this page first, then the others.

## Identity

A fast editor. Agentic when you ask.

Editor first. Agents second, and only on demand. Nothing else is identity.
Which agents, which systems, how they connect, whether a key is needed: all
details of the current version. Keep them out of the headline and the first
paragraph. "Markdown" is a detail too: it is what rubrique does best, not
what it is.

## One line

A fast editor. Agentic when you ask.

## Short description

> A fast editor. Agentic when you ask.

## Pitch

Write in a small native editor that saves exactly what you typed: Markdown
with a live preview, plus plain text, JSON, SQL and XML. Press `Cmd/Ctrl+K`
to hand the text to an agent. Review the change, then accept or
reject it. macOS and Linux, written in Rust.

## Three things that matter

1. An editor you would use with no agent installed.
2. Agents run only when you ask.
3. You decide what lands in the file. How (today: a merge screen) is a
   detail.

## Details of this version

Say these after the identity, in the present tense:

- Files: Markdown with preview, plain text, JSON, SQL, XML; images and videos open in their own view.
- Agents: Claude Code, Codex, Grok, local model (Ollama or llama.cpp).
- Every change goes through the merge screen.
- No API keys, no account.
- macOS and Linux.
- Transcription with whisper.cpp on the computer.

## Coming

- More AI providers.
- Direct API access.

So never write "command-line tools", "no API keys" or a provider name into
the identity.

## Words

Use: editor, fast, agentic, agent, when you ask, merge screen, review, skill,
note.

Avoid: AI-assisted, assistant, copilot, chat, autopilot.

## Do not claim yet

- Agents that write files or run commands from rubrique. Built-in commands
  are read-only, and rubrique asks the agent not to use tools.
- Tasks across many files, or an agent that keeps its session.
- API access, or providers beyond the four above.
- Windows.
